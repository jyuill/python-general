# Purpose

Repo for general and miscellaneous Python code examples: using specific libraries, algorithms, and other useful snippets.

# Usage

* Virtual environment has been setup using uv package.
* When starting new session, run `source .venv/bin/activate` to activate the virtual environment.
* Install required packages with uv using `uv pip install <pkg name>`.
* To update the requirements.txt file, run `uv pip freeze`.

# Contents

* Pandas: Examples of using the Pandas library for data manipulation and analysis.
* Stock market analysis: 
    - bollinger-example.py: Example of calculating Bollinger Bands using Pandas, yfinance, matplotlib.
